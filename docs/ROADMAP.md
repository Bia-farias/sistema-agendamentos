# 🗺️ Roadmap de Evolução — Agenda AI

Planejamento estratégico de próximas fases e melhorias contínuas.

---

## 🚀 Próximas Fases

### Fase 1: Expansão do Motor de IA
- [ ] Geração automática de mensagens personalizadas de recuperação de clientes inativos direto pelo chat da IA.
- [ ] Previsão de demanda para os próximos 15 dias com base no histórico de agendamentos.

### Fase 2: Experiência do Cliente Final
- [ ] Notificações push na web para confirmação de agendamentos.
- [ ] Avaliação pós-atendimento (NPS simplificado) disparado via WhatsApp.

### Fase 3: Gateway de Pagamento Integrado
- [ ] Cobrança de sinal Pix dinâmica via QR Code com confirmação instantânea via webhook (Pix Copia e Cola).
- [ ] Baixa automática da fatura no Contas a Receber após confirmação bancária.
